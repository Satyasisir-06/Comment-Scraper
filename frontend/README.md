## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   cd frontend
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```
   Runs at: `http://localhost:5173`

3. **Build for production:**
   ```bash
   npm run build
   ```
